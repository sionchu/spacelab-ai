# Spatial Analysis v2 acceptance

Branch: `codex/spatial-analysis-v2`

## SA-01 일조 시간대

- VWorld 3D가 연결된 상태에서 건물 대안을 선택한다.
- 09:00~18:00 시간대 바가 표시된다.
- 일조 / 계획 건물 음영 / 주변 환경 음영이 구분된다.
- 시간대 칸을 누르면 현재 그림자 시간이 해당 시각으로 이동한다.

## SA-02 A/B 일조 비교

- A/B 대안을 만든다.
- 비교 모드에서 두 대안이 같은 시간축으로 표시된다.
- 건물 높이·위치 차이가 있을 때 시간대별 음영 차이가 표시된다.

## SA-03 조망 분석 — PASS

실환경 확인 완료.

- 조망 위치를 선택하고 눈높이를 설정한다.
- `조망 분석`을 실행한다.
- VWorld 3D 건물/지형을 차폐 환경으로 사용한다.
- 가시 샘플 수와 예상 가시율(%)이 표시된다.

## SA-04 A/B 조망 비교

- 동일한 조망 위치에서 A/B를 분석한다.
- 비교 패널의 가시율 A/B가 Inspector 값과 일치한다.
- 서로 다른 높이/위치의 대안에서 필요한 경우 결과가 달라진다.

## SA-05 경계

표시되는 가시율은 계획 매스의 샘플 지점을 이용한 초기 공간 검토용 추정치다.

다음으로 해석하지 않는다.

- 법적 조망권 판정
- 실제 입면 가시면적 비율
- 인허가 판단
